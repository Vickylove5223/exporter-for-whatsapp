Exporter for WhatsApp – Privacy Policy

Last updated: 16 November 2026

Exporter for WhatsApp ("the extension") is a free browser extension that lets you save a copy of your own chats and contact list from WhatsApp Web to a file on your computer. This policy explains what the extension accesses and what it does with it.

Short version

Everything happens locally in your browser. Exporter for WhatsApp does not collect, transmit, sell or share any of your data. It has no servers, no accounts, no analytics and no tracking.

What the extension accesses

  • WhatsApp Web page content (only on https://web.whatsapp.com, only when you start an export): chat names, message text, sender names, timestamps, media that is already loaded in the page, and group participant names/numbers shown in group info.
  • Nothing on any other website.

How that data is used

The data is used for one purpose only: to build the export file you asked for (JSON, CSV, HTML, TXT, PDF or ZIP), which your browser then saves to your own device. The data is held in memory only for the duration of the export and is discarded afterwards.

What is stored

Only your chosen interface language is saved in the browser's local storage. No message content, contacts or personal data is stored by the extension.

Data sharing

Exporter for WhatsApp makes no network requests to any server operated by the developer or any third party. No data is sold, transferred or shared. Exported files are under your control; please store them securely and respect the privacy of the people in your conversations.

Permissions

  • sidePanel – shows the extension's interface next to WhatsApp Web.
  • scripting + access to web.whatsapp.com – reads the chats you select so they can be exported.

Limited Use

The use of information received by this extension adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements.

Not affiliated

Exporter for WhatsApp is an independent project and is not affiliated with, endorsed or sponsored by WhatsApp LLC or Meta Platforms, Inc. WhatsApp is a trademark of WhatsApp LLC.
